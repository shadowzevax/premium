# premium

Personal build of the [TizenTube](https://github.com/reisxd/TizenTube) userscript (GPL-3.0) for my own devices.

- `premium.patch`: my changes (back button → background/PiP with settings toggles, build tuned for Cobalt/Chromium 138, console logging stripped, upstream APK updater disabled).
- `userScript.js`: built automatically every 6 hours from upstream + patch (`.github/workflows/update.yml`).

All credit to Reis Can and the TizenTube contributors. Licensed GPL-3.0 like upstream.
